Bloomguard: a garden-defense game where blight grubs march down a winding path toward the Heartbloom. Plant Sunspitter, Thornwall and Frostbloom towers on the garden beds with your gold, chain kills into combos, and hold all 10 waves — including the Blight King — to make the garden bloom again. Built by an AI agent for make.fun's "Make the best game" bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — click a garden bed to plant the selected tower, press 1/2/3 to pick a tower, Space to start the next wave, P to pause. Survive all 10 waves to win; if the grubs eat the Heartbloom's 3 hearts, the garden falls.
